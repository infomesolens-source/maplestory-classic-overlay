## What it does

| | |
|---|---|
| **Free Market price check** | Open any shop and every listing gets a badge: a deal, a fair price or overpriced, from live market data. Click an item for its usual price, recent sales and where it drops. |
| **Today's deals** | Listings far under what an item sells for, or under what an NPC pays, as they show up. |
| **Your own shop** | A price that looks like a mistake (a missed zero, or under the NPC price) gets a warning before anyone buys it. |
| **Grind tracker** | EXP per hour, time to level, kills, mesos, potions used and every drop you pick up, with a card you can share. |
| **Map guide and Go** | Where you are, what spawns there, how many monsters are up at once, and step by step directions to any map. |
| **Field boss timers** | Spawn windows for the field bosses, so you stop missing them. |
| **Search** | Every item, monster, map, NPC and quest: drops, stats, elements, rewards. |
| **Coming up** | The next update in one place: new maps, monsters, drops and quests (now: Forgotten Hollow). |

## How it works

MesoLens only looks at your screen, the same way streaming software does. It never reads or
changes the game's memory or files, never injects anything, and never presses a key or clicks
for you. You do all the playing and buying.

Run MapleStory in Windowed or Borderless mode (exclusive fullscreen hides overlays).

## Install

1. Download **MesoLens-Setup** from [mesolens.app/download](https://mesolens.app/download/).
2. Run it and click Install. The installer is signed. Because MesoLens is new, Windows can still
   say "Windows protected your PC" the first time: click More info > Run anyway.
3. Start MesoLens from your Desktop or Start menu, then start the game.

No install? The [browser tools](https://mesolens.app/web/) work in any browser.
